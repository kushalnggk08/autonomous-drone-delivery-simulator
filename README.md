Autonomous Drone Delivery Simulator

A software-based 3D simulation project exploring autonomous drone navigation, waypoint tracking, payload delivery, and fault detection.

Planned Features

- 3D drone and campus environment
- Autonomous waypoint navigation
- Payload delivery verification
- Simulated environmental faults
- Fault diagnosis and recovery analysis

Technology

- React
- TypeScript
- Three.js

Project Status

Currently in the initial development stage.

Developed as part of an experiential learning project.
